# Semantic audit: `0x80122650`

## Result

`0x80122650` is one callable owner spanning the generated split at
`0x80122654`. The catalog name `ApplyGlobalRgbWithAlpha` describes its proven
ABI: truncate the caller's value to an unsigned byte, load three adjacent
global color bytes at `0x80175E70..0x80175E72`, and call `0x801220AC` with
those bytes plus the caller value as its fourth argument.

## Boundary proof

The generated manifest incorrectly presents `R 80122650 4` followed by
`R 80122654 38`. The first piece contains only:

```text
andi a3,a0,0xff
```

and unconditionally falls through. The second piece consumes that live `a3`,
loads the RGB bytes into `a0/a1/a2`, creates a 24-byte frame, calls
`0x801220AC`, and returns at `0x80122684` with stack restoration in the delay
slot at `0x80122688`. The exact semantic owner is therefore
`[0x80122650,0x8012268C)`, 60 bytes. `RenderRaceFrame` begins independently at
`0x8012268C`.

`0x80122654` cannot be invoked as an ABI function because it requires the
prefix's live `a3`; it is cataloged as an internal block.

## Caller proof

There are exactly three direct calls to the real entry:

- `0x801363D4`, passing `255`;
- `0x80138118`, passing a caller-selected byte (or zero on the adjacent path);
- `0x8013816C`, passing `255` after a four-frame `VSync` wait.

There are zero direct calls to `0x80122654`. The downstream routine
`0x801220AC` has three other internal callers, so this wrapper's distinct role
is binding the shared RGB triplet and normalizing the fourth component.

## Proven equivalent

```c
void ApplyGlobalRgbWithAlpha(uint32_t value) {
    uint8_t alpha = value;
    func_801220AC(gRgb[1], gRgb[2], gRgb[0], alpha);
}
```

The unusual argument order above is literal: address `+1` becomes `a0`, `+2`
becomes `a1`, and `+0` becomes `a2`. The broader meaning of `0x801220AC` and
the three-byte global is not asserted here.

## Confidence

Boundary and ABI status are `confirmed`; the descriptive operation name is
`known` rather than a claim about the historical identifier. The fallthrough,
live-register dependency, complete call census, and shared epilogue make the
false split unambiguous.
