# Semantic audit: `0x80112064`

## Result

`0x80112064` is the leaf `ByteSwapTwoU16Values`:

```c
void ByteSwapTwoU16Values(uint8_t *p)
{
    uint8_t b0 = p[0];
    uint8_t b1 = p[1];
    uint8_t b2 = p[2];
    uint8_t b3 = p[3];
    p[0] = b1;
    p[1] = b0;
    p[2] = b3;
    p[3] = b2;
}
```

This is deliberately named for its mechanically proven operation rather than
for a guessed packet field type. In other words, the input byte sequence
`[a,b,c,d]` becomes `[b,a,d,c]`; it independently reverses the byte order of
two adjacent 16-bit values and does not reverse the whole 32-bit word.
