# Semantic audit: `0x80105354` / `EmitGrayscaleFontGlyphPacket`

## Result

`0x80105354` is the private grayscale glyph renderer now named
`EmitGrayscaleFontGlyphPacket`:

```c
int EmitGrayscaleFontGlyphPacket(
    int glyph, int x, int y, int style, uint8_t grayscale);
```

It constructs and ordering-table-links one always-semitransparent 40-byte
`POLY_FT4`, and returns the next X pen. It is the caller-tinted sibling of the
already recovered fixed-neutral-gray `EmitFontGlyphPacket`.

## Exact owner and ABI

The exact generated range is `[0x80105354,0x80105558)`, `0x204` bytes. The
function opens a `0x10`-byte frame, has no outgoing call, returns at
`0x80105550`, and restores the stack in the delay slot at `0x80105554`. The
independent race-time formatter begins at `0x80105558`.

`a0` is the glyph index, `a1/a2` are X/Y, `a3` is style, and the fifth
incoming stack argument is loaded as grayscale. Glyph indexing and style are
not validated. The returned value is exactly:

```c
return x + 2 * glyph_width + 2;
```

## Metrics and style selection

Each metric entry is six bytes: atlas U at `+0`, atlas V at `+2`, and signed
glyph width at `+4`. Style selects the same four proven bands and heights as
the sibling renderer:

| Style | Metric base | Height |
|---:|---:|---:|
| `< 6` | `0x801CE518` | 18 |
| `6..11` | `0x801CE698` | 8 |
| `12..13` | `0x801CDCE0` | 9 |
| `14..19` | `0x801CDA88` | 16 |

Styles at least 20 reach common code without initializing the metric pointer
or height and are outside the valid authored ABI. The texture descriptor is
selected from the pointer table at `0x801A4B90` with index
`*(int16_t *)0x8019BE68 + style - 1`.

## Packet construction and render effects

The old `gPrimCursor` value at `0x80198620` becomes the packet and the global
is advanced by 40 bytes before writes. The packet is populated as:

| Offset | Value |
|---:|---|
| `+0..+3` | OT tag, payload length byte 9 |
| `+4..+6` | caller grayscale copied to R, G, and B |
| `+7` | GP0 command `0x2E` (textured, semitransparent quad) |
| `+8,+10` | `(x-1, y)` |
| `+12,+13,+14` | `(u, v, CLUT)` |
| `+16,+18` | `(x+2*width, y)` |
| `+20,+21,+22` | `(u+width+1, v, TPAGE)` |
| `+24,+26` | `(x-1, y+height)` |
| `+28,+29` | `(u, v+height)` |
| `+32,+34` | `(x+2*width, y+height)` |
| `+36,+37` | `(u+width+1, v+height)` |

CLUT packing is `(descriptor[+8] << 6) | ((descriptor[+6] >> 4) & 0x3F)`.
TPAGE combines the descriptor page coordinates and unconditionally includes
bit `0x20`, matching command `0x2E`'s semitransparency. Unlike the sibling
renderer, semitransparency does not depend on style.

The final `lwl/swl` splice prepends the packet to the active ordering-table
head selected by `0x8018AE88[*(int16_t *)0x80175CB0]`, preserving the packet's
length byte. Observable state is therefore the 40-byte cursor advance, packet
writes, and one ordering-table head replacement.

## Caller and interior-target census

The retained executable contains exactly one direct call, at `0x80110524`,
inside confirmed `DrawMappedTextString`. That owner passes the mapped glyph,
current pen, Y, selected style, and caller grayscale, then threads this
function's returned absolute X into its loop.

Generated output emits the same `0x80110524` instruction twice because
`DrawMappedTextString` has an overlapping punctuation-case translation. This
is one physical call instruction and one semantic caller, not a second call.
No external J or JAL targets an interior address. The renderer itself is
call-free.

The adjacent `DrawAsciiFontCharacter` does **not** call this function; it calls
fixed-neutral-gray `EmitFontGlyphPacket` at `0x80105CDC`. That contrast is the
evidence for the narrower grayscale name and corrects the provisional caller
description without conflating the sibling renderers.
