# Semantic audit: `0x80106350`

## Result

`0x80106350` is the confirmed GPU packet builder `EmitTexturedQuadPacket`.
It reserves and returns one 40-byte `POLY_FT4` packet from the global primitive
cursor at `0x80198620`.

## Arguments and packet layout

The register arguments are texture descriptor, signed X, signed Y, and signed
width. The first four stack arguments are signed height, semitransparency
selector, TPAGE mode bits, and a compact-UV selector. The function advances
`gPrimCursor` by 40 before writing and returns the old cursor.

The emitted packet is laid out as a normal Psy-Q `POLY_FT4` preceded by its DMA
tag:

- DMA length byte `9` at `+3`;
- neutral modulation color `(128,128,128)` and command `0x2C`, or `0x2E` when
  semitransparency is requested, at `+4..+7`;
- rectangle corners `(x,y)`, `(x+w,y)`, `(x,y+h)`, `(x+w,y+h)` at
  `+8/+10`, `+16/+18`, `+24/+26`, and `+32/+34`;
- descriptor CLUT at `+14` and descriptor-derived TPAGE combined with the
  caller's low two mode bits at `+22`;
- four descriptor UV pairs at `+12/+13`, `+20/+21`, `+28/+29`, and `+36/+37`,
  with inclusive-edge adjustments. When the compact selector is nonzero, all
  four UVs instead form a one-texel rectangle at the descriptor's first UV.

The routine only constructs the packet; it does not link it into an ordering
table. The broad caller set supplies UI and presentation rectangles, which is
consistent with this reusable packet-construction role.

## Confidence

Status is `confirmed`: the packet size, command codes, fixed color, coordinate
stores, UV/CLUT/TPAGE field placement, cursor update, return value, exact
boundary, and complete direct-call census all follow directly from the
instructions. The historical source identifier is not claimed.
