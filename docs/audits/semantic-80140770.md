# Semantic audit: guest `0x80140770`

## Conclusion

`0x80140770` is a small, independently callable scene-pass orchestrator used
by `RenderRaceFrame`.  It conditionally selects one of two view-mode-specific
passes, then submits three common race-scene layers in a fixed order.

Recommended symbol: `SubmitRaceSceneLayers` (`known`).  This name deliberately
does not assign object-type names to the five subordinate passes, whose exact
source-level identities remain unproven.

## Boundary and caller

The function has a conventional 24-byte frame at `0x80140770`, saves `ra` at
`sp+16`, and restores it at `0x801407E0..0x801407EC`.  The next independent
function begins at `0x801407F0`, so its exact extent is
`0x80140770..0x801407EF` (128 bytes).

There is one direct call in the retained image: the `jal` at `0x80124204`,
returning to `0x8012420C`.  That call lies inside the 376-byte owner frame of
`RenderRaceFrame` (`0x8012268C..0x8012482B`), not in a separate owner rooted
near `0x801243A8`.  The later `jal` at `0x801243A8` to
`BuildVisibleObjectQuadPackets` is another direct child of the same frame.

## Effective ABI and control flow

The sole caller prepares no arguments, and the callee reads none of `a0..a3`.
No return value is consumed.  Its useful result is the ordered global/GPU scene
submission side effects of its children, giving the effective prototype:

```c
void SubmitRaceSceneLayers(void);
```

The exact dispatch is:

1. Read the global suppression/override word at `0x8018AE94`.
2. When it is zero, read byte `+5` from the active view/player descriptor at
   `*(0x801D1B7C)`.  Mode `4` calls `0x8013F824`; mode `6` calls
   `0x8013E030`; every other value skips both optional calls.
3. Call `0x8013D0FC`, then `0x8013A79C`, then `0x8013982C` unconditionally.
4. Restore `ra` and return.

The mode-specific calls rejoin before the three common calls.  The nonzero
global suppression word skips only the optional mode dispatch, not the common
passes.  This makes the routine an orchestration boundary rather than a
geometry or packet-building leaf.

## Confidence and unresolved detail

- **High:** callable boundary, sole caller, argument-free ABI, exact mode
  selection, suppression behavior, child order, and void/side-effect role.
- **Medium:** `race scene layers` as the aggregate role, based on its placement
  within `RenderRaceFrame` immediately amid the known scene-submission phase.
- **Intentionally unresolved:** source names and precise object categories for
  `0x8013F824`, `0x8013E030`, `0x8013D0FC`, `0x8013A79C`, and `0x8013982C`,
  plus the semantic names of mode values `4` and `6` and global `0x8018AE94`.
