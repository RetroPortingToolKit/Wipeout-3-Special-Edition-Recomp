# Semantic audit: `0x80113914` / `TokenizeAndMeasureResourceStringBlock`

## Result

`0x80113914` preprocesses one of six fixed resource-language string blocks and
is now named `TokenizeAndMeasureResourceStringBlock`:

```c
int TokenizeAndMeasureResourceStringBlock(unsigned selector);
```

It replaces each semicolon or low control-byte string terminator with NUL,
skips inter-string control bytes, stops at the `#` end marker, and returns the
number of bytes needed when the adjacent initializer compacts the strings.

## Exact owner and jump-table aliases

Generated metadata gives `0x80113914` one `0x104`-byte owner and repeats that
same range for entries `0x80113940`, `0x8011394C`, `0x80113958`,
`0x80113964`, `0x80113970`, and `0x8011397C`. These six addresses are the
selector jump-table cases: each materializes one fixed source address and joins
the common parser at `0x80113984`. They have no independent ABI or return.

The parser returns through `0x80113A10..0x80113A14`; the next independent
owner starts at `0x80113A18`. Thus the exact callable is
`[0x80113914,0x80113A18)`.

## Selector mapping and ABI

The selector jump table at `0x8016DB64` maps values 0 through 5 to:

| Selector | Source block |

| 1 | `0x8004B4F4` |
| 2 | `0x80048004` |
| 3 | `0x8004EEEC` |
| 4 | `0x8004D208` |

The function requires a selector in `0..5`; callers satisfy that precondition.
It takes no source pointer because the blocks are fixed. It returns the signed
byte requirement in `v0` and mutates terminator bytes in the selected source.
There are no calls, stack frame, global writes, or allocations.

## Exact parsing and size semantics

Starting at the selected source, the routine repeatedly:

1. scans bytes while they are at least `0x0E` and not semicolon (`0x3B`);
2. replaces the semicolon or low control byte that ends the string with NUL;
3. counts the string bytes plus that new NUL;
4. advances past any following bytes below `0x0E` without counting them;
5. stops when the next significant byte is `#` (`0x23`), otherwise begins the
   next string there.

The `#` marker is neither overwritten nor included in the result. Bytes below
`0x0E` skipped between strings are also excluded. Consequently the returned
value is not simply the source span: it is exactly the storage required for a
packed sequence of NUL-terminated strings after those control bytes are
removed.

The adjacent owner at `0x80113A18` confirms this interpretation. On first use
it invokes this function for selectors 0 through 4, retains their maximum
returned size, allocates a destination block of that size, selects the requested
source among all six mappings, copies strings while skipping the same low
control bytes, and builds 347 pointers in `gResourceStringTable`. This proves
both the resource-string identity and the compacted-size return contract.

## Exhaustive callers and interior targets

The retained executable has five unique JALs, all in that adjacent initializer:

```text
80113A48  80113A60  80113A7C  80113A98  80113AB4
```

They pass selectors 0, 1, 2, 3, and 4 respectively and compare returns to find
the maximum allocation size. Generated output also emits exactly five calls,
so there is no overlay duplication.

No external J/JAL targets an interior instruction. The only interior entries
are the six indirect jump-table cases and direct joins to the common parser.
