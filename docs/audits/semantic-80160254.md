# Semantic audit: `0x80160254` / `SetPolyF4`

## Result

`0x80160254` is the PsyQ-compatible primitive initializer `SetPolyF4`:

```c
void SetPolyF4(POLY_F4 *packet);
```

It initializes the ordering-table packet length and GPU command byte for an
untextured, flat-shaded four-vertex polygon. Position and color fields are left
for the caller.

## Exact boundary, ABI, and return

The complete owner is `[0x80160254,0x80160268)`, exactly `0x14` bytes, matching
generated metadata:

```text
80160254  addiu v0,zero,5
80160258  sb    v0,3(a0)
8016025C  addiu v0,zero,0x28
80160260  jr    ra
80160264  sb    v0,7(a0)       # return delay slot
```

It is a frameless leaf using only `a0`. Padding starts at `0x80160268`; the
next independent SDK helper begins at `0x80160274`.

The machine register `v0` contains `0x28` on return because that constant is
used for the delay-slot byte store. However, all 22 callers ignore `v0`, and
the established PsyQ `SetPolyF4` operation is a void initializer. The constant
is therefore incidental register residue rather than a semantic result.

## Packet formula

`POLY_F4` is a 24-byte ordering-table primitive:

```text
+0x00..+0x02  existing 24-bit OT link (preserved)
+0x03         packet payload length = 5 words
+0x04..+0x06  RGB color (untouched)
+0x07         GP0 command = 0x28
+0x08..+0x17  four XY vertex pairs (untouched)
```

Equivalently, the only state changes are:

```c
packet->tag_length = 5;
packet->code = 0x28;
```

GP0 opcode `0x28` identifies a monochrome/flat, opaque, four-point polygon.
Five payload words are the RGB+command word followed by four packed XY words.
The two byte stores deliberately preserve the OT address and every caller-owned
color/coordinate byte.

The function does not allocate, link, submit, or draw the packet. Callers
typically invoke neighboring packet-mode helpers afterward and then fill RGB
and XY fields themselves.

## Direct callers and interior targets

An exhaustive aligned scan of the retained EXE finds exactly 22 calls:

```text
801094E4 801095BC 80109674 80109750 80109824 801098D4
80109A38 8010A250 8010A340 8010A40C 8010C194 8010C204
8010C260 8010C2CC 8010C324 8010C38C 8010C3E8 8010C444
8010C4A8 8010D324 8010D37C 8011075C
```

Caller windows consistently pass a packet pointer in `a0`, often advance a
global packet cursor by `0x18` bytes, then populate mode/color/coordinates.
That 24-byte stride independently confirms the `POLY_F4` layout.

There are no external direct `j` or `jal` targets at `0x80160258`,
`0x8016025C`, `0x80160260`, or `0x80160264`; every call uses the true entry.

## Identity proof

The exact PsyQ name follows from the standard packet size, length byte 5,
command byte `0x28`, 24-byte caller stride, and subsequent flat-polygon field
population. This is not merely a generic two-byte game-owned initializer.
