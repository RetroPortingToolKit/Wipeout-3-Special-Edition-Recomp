# Semantic audit: `0x80105558`

## Result

`0x80105558` is `DrawRaceTimeCentiseconds`, the high-level numeric layout
owner for race times.  It decomposes a nonnegative value into minutes,
seconds, and hundredths, emits the corresponding glyph sequence through
`EmitFontGlyphPacket`, and returns the final horizontal pen position.

## Boundary and ABI

The routine opens a `0x98`-byte frame at `0x80105558`, saves `ra` plus `s0`--
`s7` and `fp`, and contains 40 generated blocks.  Every rendering path joins
at `0x80105910`; `jr ra` is at `0x80105938` and the delay slot restores `sp`
at `0x8010593C`.  The next independent owner begins at `0x80105940`.
Therefore the exact interval is `[0x80105558,0x80105940)`, 1000 bytes
(`0x3E8`), matching the generated range.

The recovered ABI is:

```c
int DrawRaceTimeCentiseconds(
    int centiseconds, int x, int y, int main_style, int fraction_style);
```

The fifth argument is read from incoming stack `+0x10` (new-frame `+0xA8`).
Negative `fraction_style` suppresses the fractional suffix.  The returned
`v0` is the final X coordinate returned by the last emitted glyph.

## Nonnegative time layout

The signed constant-multiply divisions recover the exact decimal fields:

```c
hundredths = centiseconds % 100;
total_seconds = centiseconds / 100;
seconds = total_seconds % 60;
minutes = total_seconds / 60;
```

Only the low decimal digit of `minutes` is emitted, so the authored domain is
single-digit minutes.  The main-style glyph stream is:

```text
digit(minutes % 10), glyph 0x24, digit(seconds / 10), digit(seconds % 10)
```

Digits use glyph index `0x1A + digit`.  If `fraction_style >= 0`, the function
then emits glyph `0x25` and the two digits `hundredths / 10` and
`hundredths % 10` using `fraction_style`.  The punctuation positions and the
`/100`, `%60`, and `/10` arithmetic establish the `M:SS.hh` role without
depending on font-art appearance.

## Negative placeholder and style banks

Negative values do not enter the arithmetic formatter.  For `main_style < 6`
the routine emits glyph `0x31` three times, with an extra four-pixel gap after
the first and third emissions; if fractions are enabled it emits the same
glyph twice more.  For the other style bank it performs the analogous run
with glyph `0x28` and three-pixel gaps, using `fraction_style` for the optional
last two glyphs.  This is a style-dependent unavailable-time placeholder; the
exact visible character is deliberately not inferred from its glyph index.

When word `0x8018AE94` equals 2, each nonnegative style argument below 6 is
independently increased by 14 before emission.  Unlike the separate generic
string renderer's remap, this routine does not also test `0x801757A8`.

## `EmitFontGlyphPacket` interaction

`0x80105CDC` is the only callee.  There are 16 static JAL sites because the
formatter has specialized placeholder, punctuation, and digit paths.  Every
call follows the confirmed ABI:

```c
x = EmitFontGlyphPacket(glyph, x, y, selected_style);
```

The confirmed callee reserves and OT-links one `POLY_FT4`, selects glyph
metrics and texture state from the style, and returns the advanced X pen.
This owner carries that return through each subsequent call.  Apart from the
callee's render-packet effects, it only reads global `0x8018AE94` and mutates
private stack temporaries.

## Direct callers

An exhaustive aligned JAL scan finds exactly 16 sites, grouped by owner:

- `0x800FE978`: `0x800FEC88`, `0x800FEE1C`
- `0x80100F10`: `0x801010C0`, `0x8010115C`
- `0x80101328`: `0x801014AC`, `0x801014F8`
- `0x80106E48`: `0x801070B4`, `0x801073C0`, `0x8010760C`, `0x801077B4`
- `0x80107E18`: `0x80107EFC`, `0x80108144`, `0x80108188`, `0x801084E0`
- `0x80108534`: `0x801085F0`, `0x80108634`

The paired call sites and four-call result/menu clusters are consistent with
rendering multiple competitors' lap/race times.  No direct call targets an
interior block.
