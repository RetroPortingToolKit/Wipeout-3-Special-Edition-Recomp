# Semantic audit: `0x80160274` / `GetTPage`

## Result

`0x80160274` is the canonical Psy-Q `GetTPage` utility:

```c
uint16_t GetTPage(int tp, int abr, int x, int y);
```

Its instruction stream implements exactly:

```c
return ((tp  & 3)     << 7)
     | ((abr & 3)     << 5)
     | ((y   & 0x100) >> 4)
     | ((x   & 0x3FF) >> 6)
     | ((y   & 0x200) << 2);
```

This packs texture depth, blend mode, and VRAM page coordinates into the
PlayStation GPU TPAGE halfword. The arithmetic is entirely unsigned masks,
shifts, and ORs; high input bits are discarded.

## Boundary and effects

The exact owner is `[0x80160274, 0x801602B0)`, `0x3C` bytes or fifteen
instructions. It is one frameless basic block with no calls, branches, loads,
stores, coprocessor operations, or shared-state effects. The delay-slot OR
finishes `v0` immediately before `jr ra`. The next function begins at
`0x801602B4`; the four bytes at `0x801602B0` are not part of this owner.
