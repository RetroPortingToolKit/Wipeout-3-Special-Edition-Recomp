# Semantic audit: `0x80162690` / `SetIntrMask`

## Result and ABI

`0x80162690` is the low-level interrupt-mask exchange helper:

```c
uint16_t SetIntrMask(uint16_t mask);
```

It returns the previous interrupt mask zero-extended in `v0` and replaces the
active 16-bit mask register with the low half of incoming `a0`.

## Exact boundary and target census

The generated range assigns `[0x80162690, 0x801626A8)`, exactly `0x18` bytes,
to this frameless six-instruction leaf.  It returns at `0x801626A0` and performs
the new-mask halfword store in the return delay slot at `0x801626A4`.  The next
owner starts independently at `0x801626A8`.

An aligned scan of the authenticated executable finds exactly nine direct JAL
sites:

```text
8015EBFC 8015ECA4 8015EDF8 8015EE6C 8015EFF8
8015F0B0 8015F1C4 8015F404 8015F480
```

There are no direct calls to an interior instruction.

## Register indirection and exchange behavior

The leaf loads a pointer from global `0x8017A4F4`.  Its initialized executable
value is `0x1F801074`, the PlayStation interrupt-mask register `I_MASK`.
Keeping the target behind a word allows the low-level service/hardware binding
to supply the register address without embedding it in this leaf.

The exact operation is:

```c
volatile uint16_t *mask_reg = *(volatile uint16_t **)0x8017A4F4;
uint16_t old = *mask_reg;
*mask_reg = mask;       // low 16 bits only, in jr delay slot
return old;             // zero-extended lhu result
```

The old register read necessarily occurs before the replacement write.  There
is no pointer null check, mask-bit filtering, readback, acknowledgement of
pending `I_STAT` bits, COP0 status change, critical-section call, or explicit
memory barrier.  Any bits set in the written halfword enable their associated
IRQ sources at the hardware mask; zero disables every source represented by
the register.

## Caller state behavior

All nine callers are in the adjacent GPU/DMA support library.  Four sites pass
zero to disable maskable hardware sources while they update shared GPU/DMA
state; the returned old mask is saved by the surrounding owner.  The remaining
sites reload a saved word and pass it back to restore the prior mask.  Incoming
restore words may contain high bits, but `sh` discards them.

The helper changes only the selected 16-bit backend register.  It does not
alter the saved-mask globals maintained by callers, the DMA interrupt enable
register, or CPU-wide interrupt enable.  Therefore it is an I_MASK exchange,
not a complete enter/leave-critical-section operation.

## Confidence

`confirmed`: exact boundary and halfword ABI, exhaustive caller/interior-target
census, indirect register-pointer global and initialized I_MASK identity,
load-before-store ordering, zero-extension/truncation, disable/restore caller
pattern, and absence of wider interrupt-state effects are instruction-proven.
