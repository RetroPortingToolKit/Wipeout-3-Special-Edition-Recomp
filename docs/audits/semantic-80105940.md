# Semantic audit: `0x80105940` / `DrawDecimalValueWithTwoDigitFraction`

## Result and ABI

`0x80105940` draws a decimal whole-number component, a fixed separator glyph,
and a two-digit fractional component. It is now named
`DrawDecimalValueWithTwoDigitFraction`:

```c
int DrawDecimalValueWithTwoDigitFraction(
    int whole, int fraction, int x, int y,
    int font_style, int minimum_whole_digits);
```

The first four arguments use `a0..a3`; style and minimum width are incoming
stack arguments `+0x10/+0x14`. The return is the final X pen propagated from
the last glyph emission.

## Exact owner and decimal decomposition

The generated range `[0x80105940,0x80105B78)` is exact, length `0x238`. It
creates a 96-byte frame, saves `ra` and `s0..s5`, and returns through
`0x80105B54..0x80105B74`. The next independent owner begins at `0x80105B78`.

The whole component is repeatedly divided by ten using the signed
multiply-high quotient sequence with `0x66666667`; up to five remainders are
saved. If it reaches zero before `minimum_whole_digits`, remaining positions
are filled with zero. Digits are emitted most-significant first as glyph
`digit + 0x1A` through `EmitFontGlyphPacket`, threading each returned pen into
the next call.

It then emits fixed glyph `0x25` as the separator. The fraction is decomposed
the same way but forced to at least two digits, so values `0..9` receive a
leading zero. Authored callers supply nonnegative components, commonly a
quotient and remainder modulo 100; the function has no negative-value or
range validation.

Every glyph call receives the common Y coordinate and font style. The helper
does not write globals directly; GPU packet/cursor/ordering-table effects are
owned by `EmitFontGlyphPacket`.

## Callers, targets, and overlay accounting

Exactly five executable calls target the true entry:

```text
80109EBC 8010A61C 8010A69C 8010A970 8010A9EC
```

Three call paths explicitly compute quotient and remainder by 100 before the
call, proving the two-digit fractional interpretation. The other two draw
zeroed/default values with whole minimum width two. All consume only the
rendered result/state expected of the shared font path.

No external direct jump or JAL targets an interior instruction. An exact-body
scan finds only `0x80105940`, so overlay overlap introduces no duplicate owner
or duplicate logical callers.
