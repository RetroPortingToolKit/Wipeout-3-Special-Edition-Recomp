# Semantic audit: `0x80110198` / `LoadQuadTextureCoordinates`

## Result

`0x80110198` is `LoadQuadTextureCoordinates`, the source loader immediately
preceding the horizontal mirror, vertical mirror, and quarter-turn helpers.
Unlike those functions it does not permute existing values: it fetches the
base four `(u,v)` pairs from a texture descriptor.

## Exact boundary and ABI

The generated range table proves `[0x80110198, 0x8011024C)`, exactly `0xB4`
bytes and one block. It is frameless and call-free, returns at `0x80110244`,
and performs its final halfword store in the return delay slot at
`0x80110248`. `MirrorQuadHorizontalCoordinates` begins independently at
`0x8011024C`.

The recovered nine-argument ABI is:

```c
void LoadQuadTextureCoordinates(
    int16_t texture_index,
    int16_t *u0, int16_t *v0, int16_t *u1, int16_t *v1,
    int16_t *u2, int16_t *v2, int16_t *u3, int16_t *v3);
```

`texture_index` arrives in `a0`; only its low 16 bits matter and they are
sign-extended before multiplication by four. The first three output pointers
use `a1..a3`, while the other five are incoming stack arguments
`+0x10..+0x20`. The routine establishes no scalar return value.

## Data behavior

The signed index selects a word pointer from the table rooted at
`0x801CE96C`. From that descriptor, the routine reads unsigned halfwords at
offsets `+0x16`, `+0x18`, `+0x1A`, `+0x1C`, `+0x1E`, `+0x20`, `+0x22`, and
`+0x24`, and writes them in order through the eight output pointers. Thus the
output tuple is:

```text
(u0,v0,u1,v1,u2,v2,u3,v3) = descriptor[0x16..0x24 by halfword]
```

The repeated pointer-table loads do not change semantics. There is no bounds,
null, or alignment check, no global mutation, and no GPU/MMIO access. The
callers subsequently select adjacent mirror/rotation helpers over these same
eight pointer slots, establishing their texture-coordinate role.

## Callers and target proof

Exactly two calls target the entry:

```text
0x8010B218  0x8010BE30
```

Both provide stack-backed eight-halfword coordinate workspaces and continue
into the shared orientation-helper selection. No direct call or jump targets
an interior instruction, and there is no duplicate generated body or overlay
instance.
